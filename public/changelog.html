    Suggested streaming links can now use service branding colors instead of gray icons. Enable colors and customize each service's color in the extension popup. It looks like this:

  • New

    Follow status in friends' recent activity

    Green ticks and muted-red crosses beside nicknames now show whether users follow you back on the friends' recent activity page:

  • Improved

    Less automation in imported release artists

    To be honest it was my fault for forgetting to put several guardrails on considering that the user might just miss the changes done here. Instead of automatic work that was done on sections 1.3a and 1.4 on import it will now sit behind the button and require user input to do the same thing.

    Discography progress

    Added an option to hide overall discography coverage when it is zero. Fixed bug where when several editions are rated the release wasn't counted.

3.2.0

7 November 2026

Discography progress, more credits, and follow-status improvements

  • New

    Discography listening progress

    Artist pages now show how much of a discography you have rated or marked as listened, with progress bars for each release category and overall coverage. Choose which categories count toward your overall progress in the extension popup; albums, EPs, and mixtapes are included by default.

  • New

    Suggested credits from Metal Archives

    Metal Archives imports now suggest credits.

  • Improved

    Follow status on your friends page

    Follow status now appears beneath names in your friends list, so you can see which users you follow also follow you back. Fixed follow-status loading in Firefox.

  • Improved

    Spotify search diagnostics

    Added more detailed diagnostics for failed Spotify searches to help identify network errors and blocked requests. I am still fighting demons when working with Spotify.

3.1.0

6 November 2026

Profile, comment, and submission improvements

  • New

    Follow status on user profiles

    See whether another user follows you directly in their profile details, with a green "follows you" or muted red "does not follow you" indicator.

  • New

    Load all release comments

    Added a Load all comments button beside the Comments heading on release pages. Comments load in batches with a short pause between requests, and you can stop loading at any time. It is very jank and I got timeouted by Cloudflare during testing but with current delay it should work fine. No, I can't load all of them in one request, I tried.

  • New

    List comment redesign

    List comments are now larger and easier to read, with resizable panels, a bigger editor, and Top and Bottom buttons to jump through the comments.

  • New

    Tracklist capitalization controls

    Added buttons to convert track titles to sentence case or title case when submitting a release. Tracklist controls are also grouped in a redesigned toolbar.

  • Fixes

    Unknown dates in artist timelines

    Improved handling of unknown member joining and leaving dates. Estimated or uncertain membership periods now use faded, dashed bars with explanatory tooltips, rather than treating an unknown leaving date as confirmed membership through the present.

  • Fixes

    Imported artist aliases and credits

    Further improved alias handling in suggested credits, including artist names with localized display names. An explicit warning now appears when an import automatically sets a credited artist name, so you can check it before submitting.

  • Improved

    Shorter Spotify search waits

    Reduced the maximum wait for Spotify search results from 12 seconds to 7 seconds, so searches without a matching release finish sooner.

3.0.2

3 November 2026

Search, import, and compatibility fixes

  • Fixes

    Apple Music search accuracy

    Apple Music searches now check both the artist and release title instead of accepting the first result.

  • Fixes

    Spotify search reliability

    Improved handling of searches containing percent signs and results that are still loading. Searches now wait for matching releases instead of stopping at unrelated results, and give temporary Spotify error screens time to recover. It means that the loading icon can be spinning for a while for the releases that are not even on Spotify because it will do the full 12 seconds await, but it should be better for releases that actually do have matching data.

  • Fixes

    Tidal label imports

    Tidal imports now suggest a label from the release's copyright information.

  • Fixes

    Artist aliases in suggested credits

    Fixed alias handling when linking imported artists and suggested credits. Names that differ from the selected RYM artist's name are preserved as credited aliases, while matching names no longer receive unnecessary aliases. These choices are shared between release artists, track artists, and suggested credits. dyslexicon will probably tell me if that patch worked or not.

  • Fixes

    Timeline and maps on translated pages

    Improved recognition of translated Members headings for the artist timeline. Concert map links and timeline release markers no longer depend on English Shows or discography headings.

3.0.0

November 2026

First major release since I refactored the entire extension

  • Improved

    Suggested credits from imports

    The biggest thing in this update: less typing out credits by hand. ArkfallOverfall added a possibility to get guest artists from releases when importing from Apple Music. I used her base implementation, refined UI and UX and have added the credits scraping for everything. And then I did that for six more services.

    Imports can now suggest release and track credits from Apple Music, Spotify, Deezer, Tidal, Qobuz, Discogs, and Bandcamp. Review the suggestions and choose what to add to your submission.

    Bandcamp credit pulling is very messy, but it still makes submitting easier. I haven't tested it on every album, so please report anything unexpected.

    I plan to do the same for other streaming services. These came first because I personally use some of them and they have good credit data (not Bandcamp, but I use it often). I wanted to do all of them, but ran out of gas and got exhausted. More to come once I've recovered a bit.

  • New

    More places to import music from

    Added release imports from Traxsource, NTS Radio, Mixcloud, Tidal, and Deezer.

  • New

    Bonus track recognition

    Imports can now recognize bonus tracks and tag them in the tracklist. One less thing to fix manually.

  • Fixes

    Discogs authentication fixes

    Fixed authentication handling for Discogs imports.

  • Improved

    WhoSampled and Wikipedia button redesign

    Redesigned and moved the WhoSampled and Wikipedia buttons on release pages. Their colors can also now be customized in the extension menu. I think it is a good UX now, but let me know.

  • New

    Jump straight into search

    Press `/` while you're not typing in another field to focus the search bar directly.

  • Fixes

    Hide Ratings on label and classifier pages

    Fixed Hide Ratings not working on label and classifier pages.

  • Fixes

    Page sizes on tag pages

    Fixed adding the configured collection page size to tag-page links.

  • Fixes

    Keep page sizes already in links

    Links that already specify a page size no longer have it replaced by the extension's default.

  • New

    Recent collection view

    Added the Recent view to the collection view options.

  • Fixes

    Image-resize arrows

    Added the arrow icons on the image-resize buttons to match the direction they actually resize in.

  • New

    Clear profile locations during submission

    Added clear buttons for location fields on the profile submission form.

  • New

    Search hints on artist profiles

    You can now see an artist's search hint directly on their profile.

  • Fixes

    Profile image previews

    Fixed preview handling for images on profiles during edit of the other notes section.

  • Improved

    Capitalization beyond English

    Improved capitalization handling for non-English characters in imported titles and tracklists.

  • Fixes

    Apple Music links without the extra blank tab

    Fixed Apple Music links opening an unnecessary blank tab on Safari. Also should fix an annoying thing when it tried to open iTunes.

  • Improved

    Spotify search and error logging

    Improved Spotify search diagnostics and error logging, so when something goes wrong there is more useful information to work with. Spotify is a mess and the more I work with it the more I hate it.

  • Improved

    Qobuz Search improvements

    The chance that Qobuz search will return the correct release has been improved.
