EvenBetterRYM

RateYourMusic enhancements

Version 2.8.1

October 2026

  • HOTFIX

    Spotify search hotfix

    Spotify opened separate windows for each search result, which was fixed (I hope and pray)

  • HOTFIX

    Reference link alignment

    Adjusted Wikipedia and WhoSampled link alignment beside release titles, keeping artist information on its own line.

  • HOTFIX

    Collection column management

    Added a toggle for custom collection columns and an option to restore RYM's defaults. Toggling column management now updates open music collections while preserving your saved column choices.

  • Improved

    Improved filters for collections

    Added more filters, an ability to customize list of the columns and preserve it, page sizes and other things. Everything can be enabled/disabled as always. Thanks carbonic for the link. Expect issues, something is probably broken because that was a massive thing to implement.

  • New

    See release reception at a glance

    Release pages now include a summary of rating reception, from Panned to Acclaim, with a ranked breakdown of rating groups. You can find it under the rating distribution. Thanks polacheck for the first version of the implementation.

  • New

    Browse more release artwork

    Pulls more images from matching Discogs release issues in a carousel on music release pages. Idea and most of the implementation by MauroMauricio

  • New

    Useful reference links

    Find a release on Wikipedia or WhoSampled directly from its RYM page. Idea and most of the implementation by MauroMauricio. Expect Wikipedia links on artist and genre pages in the future.

  • Improved

    More reliable streaming links

    Streaming searches now better respect your region. Also changed how it functions with non-latin characters in almost every streaming service. Should be more reliable.

  • Improved

    Fine-tune image crops

    Spotify search overhaul

    Spotify search moved from API to UI scraping. It is slower but shouldn't get rate-limited now. Probably the ugliest code I've ever written.

  • Fixes

    Hide-page bugfix

    Fixed Hide Ratings on automatic recommendations

  • Fixes

    Discogs country bugfix

    Country was not pulled correctly if issuing country on Discogs was set to Russia.

  • Fixes

    + [unknown artist] button works again

    The + [unknown artist] button now functions correctly.

  • Fixes

    Timeline handling of bands without roles

    Timeline feature used to brake if there was no role information. Added a fallback for those cases.

  • Fixes

    + (no label) button bugfix

    The + (no label) button could rarely jump to other fields because it was connected to the clear button and not to the label field. That was patched.

Thanks for using EvenBetterRYM. Find the project on GitHub or RYM.
