RateYourMusic enhancements

3.0.0

November 2026

First major release since I refactored the entire extension

  • Improved

    Suggested credits from imports

    The biggest thing in this update: less typing out credits by hand. ArkfallOverfall added a possibility to get guest artists from releases when importing from Apple Music. I used her base implementation, refined UI and UX and have added the credits scraping for everything. And then I did that for six more services.

    Imports can now suggest release and track credits from Apple Music, Spotify, Deezer, Tidal, Qobuz, Discogs, and Bandcamp. Review the suggestions and choose what to add to your submission.

    Bandcamp credit pulling is very messy, but it still makes submitting easier. I haven't tested it on every album, so please report anything unexpected.

    I plan to do the same for other streaming services. These came first because I personally use some of them and they have good credit data (not Bandcamp, but I use it often). I wanted to do all of them, but ran out of gas and got exhausted. More to come once I've recovered a bit.

  • New

    More places to import music from

    Added release imports from Traxsource, NTS Radio, Mixcloud, Tidal, and Deezer.

  • New

    Bonus track recognition

    Imports can now recognize bonus tracks and tag them in the tracklist. One less thing to fix manually.

  • Fixes

    Discogs authentication fixes

    Fixed authentication handling for Discogs imports.

  • Improved

    WhoSampled and Wikipedia button redesign

    Redesigned and moved the WhoSampled and Wikipedia buttons on release pages. Their colors can also now be customized in the extension menu. I think it is a good UX now, but let me know.

  • New

    Jump straight into search

    Press `/` while you're not typing in another field to focus the search bar directly.

  • Fixes

    Hide Ratings on label and classifier pages

    Fixed Hide Ratings not working on label and classifier pages.

  • Fixes

    Page sizes on tag pages

    Fixed adding the configured collection page size to tag-page links.

  • Fixes

    Keep page sizes already in links

    Links that already specify a page size no longer have it replaced by the extension's default.

  • New

    Recent collection view

    Added the Recent view to the collection view options.

  • Fixes

    Image-resize arrows

    Added the arrow icons on the image-resize buttons to match the direction they actually resize in.

  • New

    Clear profile locations during submission

    Added clear buttons for location fields on the profile submission form.

  • New

    Search hints on artist profiles

    You can now see an artist's search hint directly on their profile.

  • Fixes

    Profile image previews

    Fixed preview handling for images on profiles during edit of the other notes section.

  • Improved

    Capitalization beyond English

    Improved capitalization handling for non-English characters in imported titles and tracklists.

  • Fixes

    Apple Music links without the extra blank tab

    Fixed Apple Music links opening an unnecessary blank tab on Safari. Also should fix an annoying thing when it tried to open iTunes.

  • Improved

    Spotify search and error logging

    Improved Spotify search diagnostics and error logging, so when something goes wrong there is more useful information to work with. Spotify is a mess and the more I work with it the more I hate it.

  • Improved

    Qobuz Search improvements

    The chance that Qobuz search will return the correct release has been improved.

    It has been that kind of update.
